# Function-centric deobfuscation workbench UI

Design the D810 IDA user experience around function-scoped, evidence-driven deobfuscation rather than a flat global rule list. The work includes the config-v2 round-trip correctness prerequisite and a native dockable workbench specification.

## Acceptance Criteria

A committed design spec defines personas, goals and non-goals, config-v2 correctness requirements, workbench information architecture, state/data flow, error and abstention semantics, thin Qt boundaries, staged delivery, and unit/runtime/e2e/manual IDA verification criteria.
